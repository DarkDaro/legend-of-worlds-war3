# archive

Склад устаревших материалов: старые версии документов, отработанные отчёты и заметки.

Данные сайта лежат не здесь, а в архивных ветках:
- archive/template-table — ini-данные игры для парсинга объектов;
- archive/mini-site — мини-версия «Лавки предметов» (страница, база предметов, иконки).
