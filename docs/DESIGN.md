# DESIGN — дизайн-система Legend of Worlds

Сайт выглядит как тёмный космос со стеклянными неоновыми карточками. Не потому что так модно. Я перебрал варианты, и этот первым не надоел через неделю. Тёмный фон щадит глаза в три ночи, проверено. Один циановый акцент не даёт превратить страницы в ёлку. Стекло поверх градиента прячет то, что фон нарисован градиентами, а не фотографиями.

Ниже система: токены, палитра, эффекты, правила. Писал для себя, чтобы через полгода не подбирать оттенок по памяти.

Состояние на 07.11.2026. Источник истины — файлы в `css/`; этот документ
фиксирует систему и её токены, а не заменяет их. Карта селекторов —
`css/INDEX.md`, архитектура страниц — `docs/ARCHITECTURE.md`.

## 1. Принципы

- Неоновая тёмная тема: один акцент (cyan `#00e6ff`) + семантические цвета
  ролей/статов; никаких произвольных новых оттенков без записи здесь.
- Стекломорфизм как основной материал поверх «космического» фона.
- Движение — микро- и только: shimmer заголовков, stagger-появление карточек,
  hover-подъёмы. Всё гасится `prefers-reduced-motion`.
- Деградация вместо поломки: без поддержки blur — плотный фон той же гаммы;
  на мобильных blur выключен ради производительности.
- Anti-slop: компонент или цвет сначала попадают в CSS и в этот документ,
  потом в разметку. Ничего «примерно такого же».

## 2. Палитра и токены

Определены в `:root` (`base.css`):

| Токен | Значение | Назначение |
|---|---|---|
| `--glass-bg` | `rgba(15, 23, 42, 0.5)` | фон стекла |
| `--glass-bg-hover` | `rgba(15, 23, 42, 0.65)` | фон стекла при hover |
| `--glass-blur` | `12px` | размытие карточек/таблиц |
| `--glass-border` / `-hover` | `rgba(0,230,255,.12)` / `.35` | рамки стекла |
| `--glass-subtle` / `-hover` | `rgba(0,255,255,.04)` / `.08` | подложки, кнопки, теги |
| `--glass-tag-bg` / `-border` / `-active` | `.06` / `.15` / `.15` | теги-фильтры |
| `--text-primary` / `-secondary` / `-muted` / `-dim` | `#e0f0ff` / `#8aa0c0` / `#6b7c99` / `#5a7a9a` | текст |
| `--accent-cyan` | `#00e6ff` | единственный акцент |
| `--neon-glow` | `0 0 20px rgba(0,230,255,.2), 0 0 60px rgba(0,230,255,.08)` | мягкий glow |
| `--neon-glow-strong` | + `inset 0 0 15px …` | активный glow |

База страницы (`body`): фон `#0b0e14` + радиальный градиент
`#1a2330 → #05070a` из верхнего левого угла; текст `#e3e9f5`;
внешние поля `24px 32px`; `line-height: 1.5`.

Семантические цвета:

- Атрибуты героев: сила `#ff5555`, ловкость `#55ff55`, разум `#55aaff`
  (бейджи карточек — приглушённые пары: `#ffaaaa`, `#aaffaa`, `#aaccff`).
- Роли (`effects.css`): tank `#ffaa66`, bruiser `#ff8844`, damager `#ff6666`,
  assassin `#cc44ff`, initiator `#ffcc00`, controller `#44ccff`,
  healer `#55ff55`, support `#66aaff`; базовая плашка роли — `#ffd966`.
- Бейджи предметов (`items.css`): базовый `detail-badge` — cyan-контур;
  `badge-danger` `#ff4444` (боссовый дроп), `badge-unique` `#ff6b35`
  (1 на героя), `badge-class` `#e040fb` (класс предмета).
- Редкости карточек предметов: дешёвые `opacity .85`, средние `.92`,
  дорогие `1` + усиление text-shadow (дешёвые → дорогие).
- Кнопки: `btn-primary` — зелёный градиент `#00cc66 → #00ff88` (действие),
  `btn-secondary` — контур cyan `#00e6ff` (навигация-действие).

## 3. Типографика

- Пара: `'Segoe UI', 'Inter', system-ui, sans-serif` (без внешней загрузки).
- `h1` — 2.4rem, белая заливка текста + cyan shimmer-градиент
  (`titleShimmer`, 6s, бесконечно; при reduced-motion выключен), подчёркивание
  2px cyan, свечение `text-shadow`.
- Тон задают токены текста из §2; числовые стат-таблицы — `#ffd966`
  заголовки / `#d0e4ff` ячейки.

## 4. Стекломорфизм

Три уровня стекла (от большого к малому):

| Поверхность | Фон | Рамка | Радиус | Blur |
|---|---|---|---|---|
| `.wiki-container` | `rgba(10,20,40,.45)` | `rgba(0,230,255,.08)` | 16px | 8px |
| `.site-header` | `rgba(15,23,42,.86)` | `#2a4060` | 24px | 8px |
| `.hero-page-container` | `rgba(18,25,40,.9)` | `#2a4060` | 24px | 8px |
| карточки/таблицы/модалки | `var(--glass-bg)` | `var(--glass-border)` | 8–12px | 12px |

Деградация:

- `@supports not (backdrop-filter: blur(1px))` — плотные заменители
  `rgba(15,23,42,.92)` / `#0f172a` (`info.css`, `armor-calc.css`,
  `bot-builds.css`).
- Мобильные ≤768px (`search.css`): blur выключен `!important` у всех крупных
  поверхностей — главная причина тормозов при скролле.

## 5. Фоны страниц и orb'ы

Каждая `body.page-*` получает сдвиг радиального градиента и лёгкий cyan
отсвет (`effects.css`), поверх — фиксированные «orb»-пятна через `::after`
(450–500px, `pointer-events: none`): heroes — справа снизу, items — слева
сверху (blue `rgba(0,128,255,.05)`), monsters — слева снизу (красный
`rgba(255,85,85,.04)`), lore — справа сверху, home — два пятна (`calc.css`).
`info-orb` — отдельный элемент с пульсом `infoOrbPulse` 6s.

## 6. Эффекты и анимации

- `titleShimmer` 6s — перелив заголовков h1.
- `fadeSlideUp` 0.4s + stagger 0.05–0.3s для первых 6 `hero-card` /
  `item-card`, первых 4 `stat-box`, первых 3 `quick-link-card`.
- Hover-подъёмы: кнопки `translateY(-2px)` + glow, `ability-card`
  `translate(4px, -3px)`; нажатие — вдавливание `translateY(1px)`.
- Навигация: подчёркивание `nav-link::after`, `scaleX 0→1`, 0.25s.
- Поиск/прочее (`search.css`): ripple-эффект, progress-бар.
- `prefers-reduced-motion` — 23 блока по файлам: анимации/переходы
  сводятся к 0.01ms, scroll — без smooth.

## 7. Текстуры

- «Ткань» — инлайн SVG-паттерн (диагональные линии, белый,
  `fill-opacity .008`) на девяти типах карточек.
- Точечная сетка в футере — SVG-кружки cyan `fill-opacity .04`.

## 8. Компоненты (карта)

- Шапка: `.site-header` + `.nav-link` (стили в `lore.css`, мобайл —
  `header-mobile.css`); у текущего раздела `.active`.
- Карточки: `.hero-card`, `.item-card` (градиентная рамка cyan→blue на
  hover через `::before`), `.stat-box`, `.quick-link-card`,
  `.monster-card`, `.version-card` и др. — общие hover/glow в `effects.css`.
- Бейджи: роли, атрибуты, `detail-badge*` (только `items.css`),
  `unique-badge`, `wip-badge`.
- Таблицы: `.hero-stats-table` — стекло, cyan-разделитель заголовка.
- Предметы: bottom sheet (`.item-bottom-sheet`), дерево компонентов.
- Кнопки: §2; микро-правила тап-целей ≥28px (соц-иконки, хлебные крошки,
  чекбоксы).

## 9. Сетка и контейнеры

Значения после расширения 07.11.2026 (решение владельца «шире и свободнее»):

| Контейнер | Было | Стало | Где |
|---|---|---|---|
| `.wiki-container` | 1600px / 24×32 | **1760px / 28×40** | `base.css`, все основные страницы |
| `.hero-page-container` | 1000px / 25px | **1200px / 28×32** | `hero-page.css`, 77 страниц героев |
| `body.page-hero-guide .wiki-container` | 1100px | **1300px** | `calc.css`, 6 гайдов |
| `.mechanics-grid` | 1000px | **1280px** | `mechanics.css` |
| `.dash-container` | 1200px | 1200px (без изменений) | `balance-dashboard.css` |

Особенности: страницы героев — двойная обёртка `.wiki-container` →
`.hero-page-container` (внутренний кап срабатывает на широких экранах, на
1280 внутренний занимает ~1134px); локальные оверрайды balance/creeps
(1200px) стали неоперационны и оставлены как безвредные. Мобильные
оверрайды: ≤600px — паддинг 14×12, радиус 12; monsters/items дополнительно
растягивают контейнер на узких экранах.

## 10. Брейкпоинты

1200 (сетка героев), 900, 800, 768 (отключение blur), 700, 600, 560, 500,
480. Минимальная проверка вёрстки — 360 и 1280 без горизонтального overflow.

## 11. Конвенции ведения

- 14 файлов `css/*.css` + генерируемый `css/all.css`; после правки любого
  `css/*.css` — `python3 scripts/build-css-bundle.py`.
- Бейджи предметов — только в `items.css`; общие hover/glow —
  `effects.css`; мобайл-оверрайды — в том же файле, что и правило.
- Файлы не удалять — переносить в `repo-archive/`.
- Новые токены/цвета/компоненты — сначала в CSS и в этот документ.
