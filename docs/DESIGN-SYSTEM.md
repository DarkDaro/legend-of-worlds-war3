# DESIGN-SYSTEM — собранная карта системы

Свод в одном файле: где что лежит и как связано. Полные описания — в
DESIGN.md (§2–§12), значения тем — в docs/themes/, история решений — в
PROJECT-META.md и SESSIONS.md. Этот файл — навигация и текущее состояние.

## Слои токенов (DESIGN.md §2–§3)

1. Примитивы: `--cyan-rgb` (акцент) + триплеты окружения §6 + двадцать
   статусных примитивов §5.
2. Семантика: `--bg-base`, `--steel`, `--panel-raised`, `--surface-*`,
   `--text-*`, `--danger`, `--gold` и остальные — компоненты читают только их.
3. Темы: блоки `html[data-theme="имя"]` в css/base.css переопределяют значения,
   имена и HTML общие.

## Палитра

- Акцент: неон `0, 230, 255`; оттенок `0, 255, 255` живёт вне примитива
  (тонкие поверхности, TD-2).
- Статусы §5 (общие для всех тем, темы их не красят): danger `255, 85, 85`,
  danger-deep `255, 68, 68`, danger-soft `255, 107, 107`, warning `255, 136, 0`,

  gold-soft `255, 217, 102`, amber `255, 193, 7`, gold-dim `170, 170, 68`,
  magic `191, 127, 255`, success `85, 255, 136`, mint `0, 255, 136`,
  mint-deep `0, 204, 102`, spring `0, 255, 170`, agility `85, 255, 85`,
  green-muted `76, 175, 80`. Информационный синий `85, 170, 255`.
- Альфа-ступени поверх примитивов: 0.04 / 0.08 / 0.12 / 0.2 / 0.35 / 0.6 / 0.9.
- Темы: [neon](themes/neon.md) (дефолт), [ashenvale](themes/ashenvale.md),
  [dark](themes/dark.md), [contrast](themes/contrast.md),

  белый/чёрный) — вне карты, решается с владельцем.

## Стекломорфизм (css/glass.css)

- Материал: `--surface-bg` (rgba surface 0.5), hover 0.65, solid, blur 12px,
  мягкая ступень 8px (шапки, контейнеры, мелкие поверхности), рамки от
  `--cyan-rgb` 0.12 / hover 0.35.
- Где применяется: шапка, панель настроек, карточки (герои, предметы,
  способности, механики, монстры, режимы, версии, поддержка, гайды, faq),
  поиски, модалки, слоты калькуляторов, таблица сравнения, контейнеры страниц
  — 94 использования var(--surface-blur*) по бандлу.
- Отключение тремя путями: переключатель `data-glass="off"` (фон 0.92, blur 0,
  backdrop-filter none везде через `!important`); медиа-запрос ≤768px гасит
  стекло сам (тормоза при скролле); `@supports not (backdrop-filter)` даёт
  глухой фон старым браузерам.
- Файл вынесен из base.css 19.11 (вопрос 1 §11), в бандле идёт вторым.

## Настройки сайта (js/site-settings.js)

Хранение: localStorage `site-settings-v1`, применение — атрибуты на `<html>`,
дефолт «on» не влияет на рендер. Панель — поповер от шестерёнки в шапке; на
≤600px шестерёнка плавающая круглая справа внизу, панель открывается без
бургера. Панель слушает `site-settings:change`.

| Атрибут | Пилюля/тумблер | Что делает |
|---|---|---|
| data-sound | Звук | флаг, css не читает (контент звука позже) |
| data-anim="off" | Анимации | animation/transition none, скролл без плавности |
| data-glass="off" | Стекломорфизм | blur 0, фон 0.92, backdrop-filter none |
| data-fx="off" | Тяжёлые эффекты | орб и свечение курсора убраны, text-shadow none |
| data-text="on" | Яркий текст | шкала §7 светлеет на ступень (примерная, e1b623f) |
| data-decor="off" | Фон главной | картинка арены убрана, раскладка не сдвигается (примерная) |
| data-theme | Тема | ashenvale / dark / contrast / astral / winter, «По странице» возвращает разметку |

theme-color на 117 страницах следует за темой через карту THEME_COLORS.

## Геометрия и движение

Мораторий владельца 09.11: кнопки, паддинги, марджины не трогаются — темы
и настройки меняют только цвета. Контейнеры: wiki 1760, герои 1200, гайды
1300. Движение §9 общее, data-anim глушит целиком.

## Проверки

- scripts/tmp/theme-check.mjs — 46 пунктов: разметка, пилюли, персистентность,
  стекло (вкл/выкл/мобильный авто), примерные настройки, все темы на heroes,
  консоль. Трекается в репо.
- scripts/tmp/settings-check.mjs — 14 проверок панели.
- Гейты CI: check-links (4251 ссылок), check-text, check-header-sync,
  check-counters локально.

## Ждут решения владельца

- TD-15: нейтральные белый/чёрный — 34 значения / 118 вхождений литералов,
  отдельное решение после палитр.
- Идеи настроек, не заведённые: размер шрифта (геометрия — вне моратория),
  монохром статусов (перекрашивает семейства §5), шкала скорости анимаций
  вместо on/off, авто-тема по prefers-color-scheme. Каждая требует решения
  по мораторию или по семантике статусов — без владельца не заводить.
