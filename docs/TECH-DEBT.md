# TECH-DEBT — реестр техдолга

Долг, который копится при работе, живёт здесь, а не в голове и не в переписке. Решение владельца 18.11.2026: долги фиксировать сразу при обнаружении, каждый с ценой закрытия.

Формат: ID, что именно, где, чем мешает, сколько стоит закрыть, статус. Статусы: открыт, отложен, принят, закрыт (с датой). Номера не переиспользуются: закрытая запись остаётся в списке как память.

Связи: план консолидации и слои токенов — DESIGN.md §10 и §2; решение о фундаменте — журнал решений PROJECT-META (18.11); ритуал пополнения — RULES.md §2.11.

## Как пополнять

- Новый долг пишется в день обнаружения, одним рядом таблицы, без «потом запишем».
- Долг без цены закрытия не считается описанным: цена это либо чанк плана §10, либо отдельный заход с оценкой.
- Долг закрывается только правкой статуса и датой, из реестра строки не удаляются.
- При закрытии долга в css или скриптах ссылка на ID в комментарии остаётся и становится пометкой «погашено TD-N».
