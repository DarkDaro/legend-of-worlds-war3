# docs/ — система работы проекта

Проект ведёт один человек. Эта документация — не декорация, а его инструмент управления: она держит темп, память и качество там, где у команд стоят совещания, ревью и планёрки. Каждая правка фиксируется, каждое решение датировано, каждое обещание лежит в бэклоге с датой закрытия.

## Витрина проекта

- Карта **Legend of Worlds** для Warcraft III: живёт годами, 31 версия в архиве обновлений (v3.0 → v6.9)
- Сайт-энциклопедия поверх карты: **117 HTML-страниц**, 74 героя, 222 предмета, 408 стадий ИИ, **4134 внутренние ссылки** под автоматической проверкой
- Карта, сайт и лор сделаны и ведутся одним автором

## Как ведётся работа

- **Мелкие чанки.** Одна правка — один коммит — один пуш. История читается как журнал работы, а не завал.
- **Проверки вместо памяти.** Три линтера (`check-links`, `check-text`, `check-header-sync`) гоняются в CI на каждый пуш: 117 страниц и 4 тысячи ссылок не обходятся вручную — их держит система.
- **Решения фиксируются.** Дата, решение, причина — в паспорте проекта. Закрытое не переобсуждается: время уходит вперёд, а не на повторение пройденного.
- **Долгая дистанция.** Карта старше сайта и переживала паузы без потери темпа — журнал и бэклог устроены так, чтобы работа возобновлялась с любого места. Темп задаёт система, а не настроение.

Правила работы и полный журнал решений — в [PROJECT-META.md](PROJECT-META.md). Позиция автора — в [README.md](../README.md) и на странице манифеста сайта.
