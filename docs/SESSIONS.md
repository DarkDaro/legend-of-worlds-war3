## 07.11.2026 (продолжение 5) — тестовый коммит для ресинка VS Code-клона

Владелец пытается забрать изменения в свой VS Code-клон: push отклоняется (non-fast-forward), pull — «refusing to merge unrelated histories». Причина известна: у клона другой корневой коммит, с GitHub нет общего предка, поэтому merge-команды для него запрещены — это защита, а не поломка. Лечение прежнее: `git fetch origin` и `git reset --hard origin/main` (в PowerShell — двумя отдельными строками, `&&` старый PowerShell не понимает); кнопку Sync в этой копии не использовать. VS Code может предлагать --allow-unrelated-histories — не соглашаться.

Песочница к этому моменту снова пересобиралась — клон восстановлен из GitHub заново, кончик ac47b1d, токен цел. Настоящий коммит — пробный маркер: после него владелец делает fetch + reset --hard origin/main и должен увидеть этот коммит кончиком (`git log --oneline -1`); отчёт владельца сверяется с remote.
