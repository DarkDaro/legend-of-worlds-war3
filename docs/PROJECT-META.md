# PROJECT-META — паспорт проекта

**Проект:** Legend of Worlds — сайт карты для Warcraft III
**Репозиторий:** DarkDaro/legend-of-worlds-war3
**Сайт:** https://darkdaro.github.io/legend-of-worlds-war3/
**Владелец и автор:** DarkDaro (права — в LICENSE.md)
**Стек:** статичные HTML/CSS/JS без сборщика; GitHub Pages, деплой из корня main, .nojekyll
**Ветки:** main — сайт; archive/template-table — ini-данные игры; archive/mini-site — мини-версия «Лавки предметов»

## Как ведётся работа

- Коммит: `тема: что сделано; деталь; чем проверено` — коротко, простым языком, одна причина.
- Темы: вёрстка, дизайн, контент, скрипт, инфра, a11y, фикс, метафайл.
- Работа идёт мелкими чанками; перед правкой страницы — её инвентаризация, контент переносится дословно.
- Правила комплекта (Rules Kit) сильнее привычек, указание владельца сильнее правил.
- HeroData\archive — старый архив владельца на его ПК, вне репозитория: не трогаем. Локальные незатреканные папки не трогают ни пуши, ни правка истории, ни git reset --hard.
- Правка истории — точечная: меняются только согласованные сообщения, имена авторов и мёртвые блобы; всё остальное байт в байт. Перед прогоном — bundle-бэкап всей истории.

## Рабочие папки

- docs/ — этот паспорт, роадмап, бэклог, журнал сессий.
- scripts/ — скрипты, использованные при работе (инвентаризация, аудит целостности).
- archive/ — склад устаревших документов и отчётов; данные сайта лежат в архивных ветках, не здесь.

## Состояние main на 2026-11-07

- 544 файла, ~42,5 МБ: 116 HTML-страниц, 46 JS, 36 CSS, 517 картинок, vendor (Font Awesome), sitemap.xml.
- Линтеры из комплекта ещё не перенесены, CI нет; Pages деплоится из ветки main.
- Аудит целостности: все JS без синтакс-ошибок, все HTML закрыты.
