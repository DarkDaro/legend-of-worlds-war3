# PROJECT-META — паспорт проекта

Паспорт: кто, где и по каким правилам работает. Сухой, и должен быть сухим.

**Проект:** Legend of Worlds — сайт карты для Warcraft III
**Репозиторий:** DarkDaro/legend-of-worlds-war3
**Сайт:** https://darkdaro.github.io/legend-of-worlds-war3/
**Владелец и автор:** DarkDaro (права — в LICENSE.md)
**Стек:** статичные HTML/CSS/JS без сборщика; GitHub Pages, деплой из корня main, .nojekyll
**Ветки:** main — сайт; archive/template-table — ini-данные игры; archive/mini-site — мини-версия «Лавки предметов»

## Как ведётся работа

- Коммит: одна строка, строчными, по-человечески. Без тире, стрелок, точек с запятой и служебных префиксов. Отчёты о проверках в сообщение не тянут.
- Работа идёт мелкими чанками; перед правкой страницы — её инвентаризация, контент переносится дословно.
- Правила из этого паспорта сильнее привычек; указание владельца сильнее правил.
- HeroData\archive — старый архив владельца на его ПК, вне репозитория: не трогаем. Локальные незатреканные папки не трогают ни пуши, ни правка истории, ни git reset --hard.
- Правка истории — точечная: только согласованные сообщения, имена и мёртвые блобы, всё остальное байт в байт. Перед прогоном — bundle-бэкап всей истории.
- .gitignore: HeroData/ и archive/ — локальные папки владельца, гит их не видит; архивная папка репо называется repo-archive/, чтобы имена не сталкивались.

## Рабочие папки

- docs/ — этот паспорт, роадмап, бэклог, журнал сессий.
- scripts/ — рабочие скрипты (проверки, генераторы, инвентаризация).
- repo-archive/ — склад устаревших документов и отчётов; данные сайта лежат в архивных ветках, не здесь.
