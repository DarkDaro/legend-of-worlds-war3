# CSS-аудит — 2026-11-08

Полный аудит стилей сайта: ошибки, конфликты, перекрытия, мёртвый код, недоработки. Это снимок состояния на дату; правки по нему — отдельными коммитами, задним числом документ не переписываю.

Правило аудита: находка попадает в список только если она проверена, а не «похоже, что». Там, где я не уверен — так и написано.

## Как проверял

- Инвентаризация: все 32 CSS-файла (28 в `css/` + `aibot.css`, `info-auto-level.css`, `map.css`), карта подключений по всем 116 HTML.
- Свежесть бандла: пересборка `scripts/build-css-bundle.py` → diff с `css/all.css`.
- Статический разбор всех файлов парсером (tinycss2): синтаксис, свойства, селекторы, `url()`, `var()`, `!important`, media-запросы, z-index.
- Кросс-чек: 1114 классов из CSS против всего HTML (116 страниц) и всех JS. Отдельно проверил динамическую сборку имён классов в JS (конкатенации вида `'tier-' + n`) — после первого прохода снял 10 ложных находок: `backdrop-filter` и `contain` оказались валидными свойствами, `type-melee/ranged` генерирует `balance-page.js`, `tier-1..8` генерирует `creeps-page.js`.
- Живой прогон в браузере: index, heroes, admiral (герой), items, map, aibot, bot-builds — ошибки страницы, консоль, computed styles, скриншоты.
- Страницы героев: у всех 77 сверены наборы CSS (идентичны), выборочно открыл admiral.

## Подтверждённые ошибки — 2

**1. `--accent` не определён нигде — 5 использований в `css/bot-builds.css`.**
Строки 244, 270, 271, 284, 291: `.bb-total-value`, `.bb-group-btn.active`, `.bb-copy-btn` красят текст и рамки через `color: var(--accent)` / `border-color: var(--accent)` без fallback. Переменной нет ни в одном CSS, ни в HTML, ни в JS — и не было никогда (`git log -S "--accent:"` пуст). Свойство молча отваливается до наследуемого цвета. Проверено в браузере: итоговые значения и кнопка «Скопировать в конструктор» рендерятся `rgb(227,233,245)` — обычный цвет текста, а не акцент. Не краш, но задуманная подсветка на странице «Сборка ИИ» не работает.
Допущение (это моё предположение, не факт): судя по фону той же кнопки `rgba(0,230,255,…)`, имелся в виду существующий `--accent-cyan: #00e6ff`.

**2. `--border-color` не определён — 1 использование, `css/storage.css:416`.**
`border: 1px solid var(--border-color, #2a3a4a)` в `.storage-info-reset`. Визуально работает только за счёт fallback: переменная мёртвая, fallback выигрывает всегда. Опасность — если кто-то однажды определит `--border-color` глобально, кнопка молча сменит рамку.

## Перекрытия селекторов

**Осознанные, работают как задумано** (порядок подключения на всех страницах единый: FA → бандл → файл страницы — проверил на balance, aibot, map, info):

- `aibot.css:4` расширяет `.hero-page-container` до 1440px (в бандле 1200px).
- `balance-dashboard.css:31` перебивает цвет `.stat-label` на своей странице (базу задаёт `home.css` из бандла).
- Цвета ролей `.role-*`: базу задаёт `effects.css` (в бандле, все страницы), `balance.css:145` и `guides.css:822` перебивают цвет на своих страницах. Работает, но разбросан по трём файлам — при переносе бейджа на новую страницу цвет будет «дефолтный» из effects.css.

**Исторические хвосты — перекрытие с тем же значением, что уже в бандле (можно сносить при чистке):**

- `balance.css:40` и `creeps.css:37`, `creeps.css:256`: `.hero-page-container { max-width: 1200px }` — то же значение, что в бандле. Комментарий в creeps.css:255 («1000px → 1200px») подтверждает: это остаток старого расширения.

**Одно имя — две независимые реализации:**

- `.compare-table` в `aibot.css` (font-size 0.85rem) и `css/compare.css` (0.82rem). Страницы вместе не грузятся, конфликта нет, но при переиспользовании таблицы в другом месте легко напороться на неожиданный размер.

**Дубли без конфликта — чистые дополнения (не трогать):** `body` в `search.css` добавляет анимацию pageIn к базовому; `.hero-card`, `.item-card`, `.stat-box`, `.quick-link-card` в `effects.css` добавляют hover-эффекты к базовым стилям из `home.css`/`items.css`/`hero-grid.css`.

## Гигиена — факты, не баги

- `!important`: 7 объявлений в 5 селекторах. Из них 2 — на мёртвом `.ability-cell`; живые: вдавливание кнопки (`effects.css`, поверх hover-теней), скрытие `.items-grid.collapsed`, `[hidden]`-паттерн фильтра предметов, высота радара. Все живые — обоснованные паттерны, хаоса нет.
- z-index: 14 значений от −1 до 10000. Лестница читаема: 1–3 локальные слои, 100–2000 оверлеи и шапка, 5000–10000 модалки/поиск. Дублей с разным смыслом не заметил.
- Брейкпоинты: 14 разных `max-width` — 1200, 900, 800, 768, 720, 700, 640, 600, 560, 500, 480, 420, 380, 360. Работает, но поддержка тяжёлая: у каждой страницы свой порог, у соседних разница в 20px. Рекомендация, не ошибка: свести к шкале из 4–5 точек.
- Цвета вне переменных: жёстких hex много — `items.css` 203, `hero-page.css` 156, `calc.css` 128, `map.css` 98, дальше меньше. Палитра на глаз согласована (циан + тёмно-синие), но правка «одним движением» невозможна. Рекомендация: новые стили — через переменные, старые — по мере касания.
- Шрифты: стек `'Segoe UI', 'Inter', system-ui` — `Inter` нигде не подключён (@font-face нет, файлов нет; в репо нет ни одного скачанного шрифта, кроме Font Awesome — поиск по всей истории git это подтвердил). Для тех, у кого Inter установлен, рендер отличается от остальных. Это не ошибка, а осознанный выбор или недоделка — решать владельцу.
- `css/INDEX.md` устарел: описывает только 14 файлов бандла из 31; 17 постраничных CSS не задокументированы; размеры части файлов не соответствуют (info.css задокументирован как 11.5KB, реально 22.5KB); в заголовке старое имя проекта HeroData.
