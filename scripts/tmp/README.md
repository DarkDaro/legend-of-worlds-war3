# scripts/tmp — разовые скрипты

Одноразовые инструменты под конкретную задачу: массовые правки css и HTML, проверки рендера браузером, сверки данных, дебаг. Каждый скрипт начинается комментарием — что делает и зачем. Постоянные гейты живут в scripts/ и в CI, здесь им не место.

Папка — копилка приёмов: скрипты читаются как образцы работы и переносятся на другие проекты. Пути внутри указаны на момент прогона, при переносе правятся под новый корень.

Запускать из корня репозитория, если в шапке не сказано иного. Скрипты не входят в сборку сайта и на страницах не используются.
