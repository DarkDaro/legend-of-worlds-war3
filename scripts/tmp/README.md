# scripts/tmp — разовые скрипты

Одноразовые инструменты под конкретную задачу: массовые правки css и HTML, проверки рендера браузером, сверки данных, дебаг. Каждый скрипт начинается комментарием — что делает и зачем. Постоянные гейты живут в scripts/ и в CI, здесь им не место.

Папка — копилка приёмов: скрипты читаются как образцы работы и переносятся на другие проекты. Пути внутри указаны на момент прогона, при переносе правятся под новый корень.

Запускать из корня репозитория, если в шапке не сказано иного. Скрипты не входят в сборку сайта и на страницах не используются.

## legacy/ — историческая копилка (21.11)

Скрипты сессий 6–8.11 и 19.11, сохранённые из внешней рабочей папки (где они могли пропасть при пересборке песочницы). Пути внутри — на момент прогонов той эпохи, к текущей структуре репо не привязаны. Структура: корень legacy/ — массовые правки и аудиты той эпохи (плюс msgmap-*.tsv — карты сообщений для pipeline переписывания истории, читаются rewrite_draft.py/rewrite_finalize.py); audit-report/ и gen_audit/ — генераторы отчётов; probes/ — точечные проверки. Старые варианты файлов, у которых в scripts/ живёт более свежая версия, помечены датой в имени (audit_integrity-2026-11-06.py, inventory_head-2026-11-06.py, probes/item-consistency-2026-11-08.mjs). Скриншоты и логи прогонов в репо не попадают сознательно — вес.
