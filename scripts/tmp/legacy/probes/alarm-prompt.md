Зачем этот файл: владелец просил не ждать чанки с открытым окном — работа идёт

ВАЖНО про формат будильника: job.schedule.expr — строка даты
«yyyy-MM-dd HH:mm:ss» в СЕРВЕРНОМ времени +08:00 (это Екб + 3 часа),
job.schedule.tz=Asia/Shanghai. Эпоха в миллисекундах парсится неверно
(537518 получил next_run_time в год 58852), а строка в екатеринбургском
времени отбивается ошибкой «should after now time». Время: «сейчас + 22
минуты», перевести в +08:00 через TZ=Asia/Shanghai date -d '+22 minutes'.
Проверить после создания через action=get: next_run_time/создание —
сегодняшняя дата.

- TD-15 (нейтральные белый/чёрный) в конвейер не брать: после палитр решить
