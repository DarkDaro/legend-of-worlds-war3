## Механика прогона

1. `git bundle create` — бэкап всех веток в песочнице.
2. Свежий зеркальный клон → `git filter-repo`: mailmap (этап A) + message-callback по SHA из таблицы (этап B) + strip-blobs-with-ids (этап C).
3. `git push --force-with-lease` всех трёх веток.
4. Проверки: лог, состав файлов трёх кончиков идентичен предпрогону (кроме удалённых блобов), авторы на GitHub, Pages 200.
5. Обновить docs/SESSIONS.md с новыми SHA — отдельный коммит.
6. Твой VS Code-клон: `git fetch` и `git reset --hard origin/main`. Незатреканные папки (HeroData\archive и остальные локальные) не пострадают — reset трогает только файлы под гитом.
